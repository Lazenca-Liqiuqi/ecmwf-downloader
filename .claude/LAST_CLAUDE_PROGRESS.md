### 3. 修复 Textual 对话框滚动问题（Codex 协助）

**问题**：
- 滚动不工作：`ScrollableContainer` 无法滚动
- 按钮不可见：底部按钮被裁切

**根因分析**（Codex）：
1. 固定高度 `height: 22` 与 `max-height: 85%` 冲突
2. `ScrollableContainer` 只有一个子节点，高度被算成视口高度
3. 焦点在按钮上，键盘滚动无效

**解决方案**：
- 使用 `VerticalScroll` 替代 `ScrollableContainer`
- 滚动区使用 `height: 1fr`（弹性高度）
- 默认焦点放到滚动区域

### 4. 清理硬编码的 grid 参数

**问题**：代码中硬编码了 `grid: [2.5, 2]` 默认值，但动态表单中没有这个字段

**修复**：
- 移除 `request_builder.py` 中的 `grid` 处理逻辑
- 移除 `cds_client.py` 中的 `grid` 处理逻辑和文档
- 移除 `task_service.py` 中的 `grid` 字段

### 5. 删除任务数量预览标签

**修改**：删除创建任务页面上方的"将创建 n 个任务"标签，因为该信息已在预览对话框中显示
